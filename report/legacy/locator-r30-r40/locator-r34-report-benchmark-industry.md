Locator R34 – Industry benchmark template

Goal: compare Locator behavior with 1–2 external providers on a few realistic scenarios.

Sections:

1. Providers
   - Example: Google Places
   - Example: Mapbox Search
   - Example: HERE Geocoding & Search
   - Example: Pelias-based stack

2. Scenarios
   - Scenario-01: Partial address in primary region.
   - Scenario-02: "Pharmacy near address".
   - Scenario-03: Reverse geocoding near building border.

   For each scenario:
   - Input
   - Locator response (quality, latency, notes)
   - Provider A response
   - Provider B response

3. Comparison
   - Strengths of Locator.
   - Weak spots vs external providers.
   - Which gaps are acceptable for RC1, which must be addressed.

4. Backlog extraction
   - Short list of features derived from comparison to be added into roadmap.
